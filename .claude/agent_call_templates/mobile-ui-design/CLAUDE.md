# CLAUDE.md — Mobile UI Design サブエージェント呼び出し仕様

## 概要

`mobile-ui-design` スキルをClaude Codeのサブエージェントとして呼び出すための仕様書。
オーケストレーターエージェントはこのファイルを参照して、UIデザインタスクをサブエージェントに委譲する。

---

## 1. サブエージェントとして呼び出すべきタスク

以下のタスクは **必ず** UIデザインサブエージェントに委譲すること：

```
- スマートフォン画面のUIデザイン・モックアップ生成
- 既存画面のレイアウト修正・コンポーネント追加
- 複数画面にわたるUI一貫性の確保
- デザインシステムに従ったHTML/JSX実装
- グラフ・チャート・カレンダー・アップロードUIの実装
```

---

## 2. 呼び出しプロンプトテンプレート

### 2.1 基本テンプレート（新規画面生成）

```
あなたはAIBODブランドのスマートフォンアプリUIデザイン専門のサブエージェントです。
mobile-ui-design スキル（SKILL.md）を必ず参照してから実装を開始してください。

## タスク
{SCREEN_NAME}画面を実装してください。

## 要件
- 画面の目的: {PURPOSE}
- 主な表示データ: {DATA_ITEMS}
- ユーザーアクション: {USER_ACTIONS}
- 使用コンポーネント: {COMPONENTS}  ← §4〜§5 から選択
- 実装形式: {FORMAT}  ← "HTML" または "React (JSX)"

## 制約
- AIBODデザインシステム（SKILL.md §2 カラーパレット）に必ず従うこと
- タップ領域は最低44×44pxを確保すること
- 日本語UIとすること（フォント: Noto Sans JP）
- モックはスマホフレーム（390×844px）内に収めること

## 出力形式
完全に動作するHTML（またはJSX）ファイルを1ファイルで出力してください。
```

### 2.2 グラフ・チャート画面テンプレート

```
mobile-ui-design スキルを参照し、グラフ・チャートを含む画面を実装してください。

## 画面名: {SCREEN_NAME}

## グラフ仕様
- グラフ種別: {CHART_TYPE}  ← 折れ線 / 棒 / 円・ドーナツ / スパークライン
- データ項目: {DATA_LABELS}
- 時間軸: {TIME_RANGE}  ← 例: 直近24時間, 週次, 月次
- ライブラリ: Chart.js（HTML時）/ Recharts（React時）

## AIBODカラー適用
- Primary線/塗り: #00C4CC（--aibod-cyan）
- Secondary: #1A3A5C（--aibod-navy-mid）
- グラデーション塗りつぶし: rgba(0,196,204,0.20) → rgba(0,196,204,0.00)
- ツールチップ: 白背景 + ネイビーテキスト

## その他の画面要素
{OTHER_ELEMENTS}
```

### 2.3 カレンダー・スケジュール画面テンプレート

```
mobile-ui-design スキルを参照し、カレンダーUIを含む画面を実装してください。

## 画面名: {SCREEN_NAME}

## カレンダー仕様
- 表示形式: {CAL_TYPE}  ← 月表示 / 週表示 / 日付ピッカー（モーダル）/ ドラム式
- 選択モード: {SELECT_MODE}  ← 単一 / 範囲 / 複数
- 特殊日表示: {SPECIAL_DATES}  ← 例: 予約済み日（ドット表示）, 休日（赤）
- 初期表示月: 今月（動的）

## インタラクション
- 月ナビ: ← 前月 / 次月 → ボタン
- 日付タップ: {ON_DATE_SELECT}  ← 例: 選択状態に切替、詳細モーダルを表示
```

### 2.4 画像アップロード画面テンプレート

```
mobile-ui-design スキルを参照し、カメラ・画像アップロードUIを含む画面を実装してください。

## 画面名: {SCREEN_NAME}

## アップロード仕様
- 枚数制限: {MAX_FILES}  ← 例: 最大5枚
- ファイル種別: {ACCEPT}  ← 例: image/* / image/jpeg,image/png
- サムネイル表示: {THUMB_LAYOUT}  ← グリッド3列 / 水平スクロール
- プログレス表示: 有（アップロード中はプログレスバー表示）

## 追加要件
{ADDITIONAL}  ← 例: OCRボタン, AIで分析ボタン, コメント入力欄
```

### 2.5 通知・アラート画面テンプレート

```
mobile-ui-design スキルを参照し、通知・アラートUIを含む画面を実装してください。

## 画面名: {SCREEN_NAME}

## アラート仕様
- バナー種別: {BANNER_TYPE}  ← インライン / トースト / AppBar直下 / 複合
- アラートレベル: {LEVELS}  ← info / success / warning / error（複数可）
- dismissible: {DISMISSIBLE}  ← true / false
- 自動消去: {AUTO_DISMISS}  ← トーストの場合: 3000ms など

## アラートトリガー
{TRIGGER_DESC}  ← 例: デバイス異常検知時、電力超過時、通信断絶時
```

## 3. オーケストレーター側の記述例（CLAUDE.md）

プロジェクトルートの `CLAUDE.md` に以下を追記する：

```markdown
## UIデザインサブエージェント

スマートフォン画面のUI実装が必要な場合は、以下の手順で専用サブエージェントを呼び出すこと。

### 呼び出し条件
- 新規画面の作成
- 既存画面のUIコンポーネント追加・変更
- グラフ・チャート・カレンダー・アップロードUIの実装

### スキル参照パス
- デザインシステム: `.claude/skills/mobile-ui-design/SKILL.md`
- コンポーネント詳細: `.claude/skills/mobile-ui-design/references/components.md`
- 呼び出し仕様: `.claude/skills/mobile-ui-design/CLAUDE.md`（このファイル）

### 出力先
- HTML モック:  `src/ui-mocks/{screen-name}.html`
- React コンポーネント: `src/components/screens/{ScreenName}.jsx`

### 注意事項
- AIBODブランドカラー（#00C4CC / #0A2540）を必ず使用すること
- デザインシステム外のカラーを使用しないこと
- タップ領域44px以上を常に確認すること
```

## 4. インストール方法

```bash
# スキルをプロジェクトに配置
mkdir -p .claude/skills/mobile-ui-design/references
cp SKILL.md .claude/skills/mobile-ui-design/
cp references/components.md .claude/skills/mobile-ui-design/references/
cp CLAUDE.md .claude/skills/mobile-ui-design/

# プロジェクトルートの CLAUDE.md に §3 の内容を追記
```

## 5. 呼び出し実例（コピー&ペースト用）

### HEMS ダッシュボード画面

```
mobile-ui-design スキル（SKILL.md）を参照してHEMSダッシュボード画面を実装してください。

画面名: ホームダッシュボード
目的: 家庭内エネルギー状況のリアルタイム把握
表示データ: 本日の電力消費量, 太陽光発電量, 蓄電池残量(%), デバイス稼働状態
ユーザーアクション: デバイスON/OFFトグル, 詳細グラフ遷移, アラート確認
使用コンポーネント: メトリクスカード2×2, 折れ線グラフ(24h), デバイスリストカード, トグル, アラートバナー
実装形式: HTML（Chart.js使用）
```
