## コーポレートカラー

AIBODのコーポレートカラーは **ネイビーインディゴ × スカイブルーの3色体系** です。
この3色のみを正式なコーポレートカラーとして使用します。

```
NAVY       #1D2087   rgb(29, 32, 135)    ネイビーインディゴ  ← 最強強調・最重要
BLUE       #0068B6   rgb(0, 104, 182)    ミッドブルー       ← 中程度強調
BLUE_LIGHT #00B3EC   rgb(0, 179, 236)    スカイブルー       ← 軽い強調・アクセント
```

### サポートカラー（補助用途）

```
WHITE      #FFFFFF   rgb(255, 255, 255)  背景・白抜き文字
BLACK      #1A1A1A   rgb(26, 26, 26)     本文テキスト基本色
GRAY_MID   #6B8299   rgb(107, 130, 153)  サブテキスト・注釈
GRAY_LIGHT #D6E8F5   rgb(214, 232, 245)  ボーダー・薄い区切り
BLUE_PALE  #BFE4F8   rgb(191, 228, 248)  薄いアクセント背景
```

### 絶対禁止
- **ティール・グリーン系は使用禁止**（コーポレートカラー外）
- コーポレートカラー外の色を新たに追加しない

## ロゴ体系

AIBODグループには4種類のロゴがあります。

### 1. コーポレートロゴ（AIBOD）
三角形を組み合わせた「A」型マーク。AIBODのメインアイデンティティ。
- 横組みロゴ（マーク＋テキスト横並び）
- 縦組みロゴ（マーク上・テキスト下）
- スローガン付き（「AI VALUE CREATOR」）

### 2. アカデミーロゴ（AIBOD ACADEMY）
角帽（graduation cap）をモチーフにしたロゴ。
- NAVY（帽子）+ BLUE_LIGHT（タッセル）の2色構成

### 3. AICロゴ
クラウド型マーク。BLUE_LIGHT（上部）+ NAVY（下部）のグラデーション構成。

### 4. AIDIロゴ
円形の幾何学マーク（カメラアパーチャー型）。NAVY + BLUE + BLUE_LIGHTの3色構成。

## ロゴ使用ルール

### 背景別ロゴ選択

| 背景色 | 使用するロゴ |
|--------|------------|
| **白・明るい背景** | ブルーマークのベーシックロゴ（カラー版） |
| **黒・暗い背景** | ブルーマーク＋白いタイプ（文字ホワイト版） |
| **青（BLUE_LIGHT/BLUE/NAVY）背景** | ホワイトロゴ（全白） |
| **画像・写真背景** | ホワイトロゴ（全白） |

### ロゴバリエーション

各ロゴには以下のバリエーションがあります：
- **カラー版**（ベーシック）: 白背景・明るい背景用
- **ホワイト版**: 青・黒・画像背景用
- **ブラック背景版**: 暗い背景用カラーロゴ
- **モノクロ版**: 白黒印刷・グレースケール用

## カラー使用ポリシー

### テキストの基本方針

- **本文テキスト → BLACK (#1A1A1A)** を基本色とする
- **見出し文字 → BLACK (#1A1A1A)**（アクセントバーはNAVYを使用してもOK）
- **NAVYは背景・強調バー・ボーダー専用**。本文テキストには使わない
- 強調したい箇所のみコーポレートカラーを使用する

### アイテム数別カラーの使い方

AIBODデザインの重要なルール：アイテム数に応じて使う色数を変える。

| アイテム数 | カラールール | 典型的な使用例 |
|-----------|------------|--------------|
| **1〜2項目** | BLUE_LIGHT **一色のみ** | バッジ・ラベルが1〜2個 |
| **3項目** | BLUE_LIGHT → BLUE → NAVY（順序通り） | ステップ3段階・フェーズ3つ |
| **4項目** | BLUE_LIGHT → BLUE → NAVY → GRAY_MID | 4段階プロセス |
| **5項目以上** | BLUE_LIGHT 一色（またはBLACK） | 長いリスト・5行以上の表 |
| 補足・サブテキスト | GRAY_MID | 説明文・注釈 |

### 禁止パターン

- 意味のある並びがないのに同じ画面で3色を混在させない
- 本文テキストにNAVYを使わない（NAVYは背景・バー専用）
- ティール・グリーン系の使用
- 絵文字の使用（番号 01/02/03 を使う）

## 表（テーブル）デザインルール

| 要素 | スタイル |
|------|---------|
| 罫線 | **BLACK**（GRAY_LIGHTは使わない） |
| ヘッダー行の背景 | **BLUE_LIGHT** |
| ヘッダー行の文字 | **WHITE、BOLD** |
| 合計・最重要行の背景 | **NAVY** |
| 合計・最重要行の文字 | **WHITE、BOLD** |
| 強調セルの文字色 | **BLUE_LIGHT**（金額・重要数値など） |
| 通常セルの文字色 | **BLACK** |

## Python実装用カラー定義（python-pptx / その他）

```python
from pptx.dml.color import RGBColor

# コーポレートカラー（3色）
NAVY       = RGBColor(0x1D, 0x20, 0x87)   # #1D2087 ネイビーインディゴ
BLUE       = RGBColor(0x00, 0x68, 0xB6)   # #0068B6 ミッドブルー
BLUE_LIGHT = RGBColor(0x00, 0xB3, 0xEC)   # #00B3EC スカイブルー

# サポートカラー
WHITE      = RGBColor(0xFF, 0xFF, 0xFF)   # #FFFFFF
BLACK      = RGBColor(0x1A, 0x1A, 0x1A)   # #1A1A1A 本文テキスト基本色
GRAY_MID   = RGBColor(0x6B, 0x82, 0x99)   # #6B8299 サブテキスト
GRAY_LIGHT = RGBColor(0xD6, 0xE8, 0xF5)   # #D6E8F5 ボーダー
BLUE_PALE  = RGBColor(0xBF, 0xE4, 0xF8)   # #BFE4F8 薄いアクセント

# フォント
FONT_LATIN = "Poppins"           # 英数字
FONT_EA    = "源ノ角ゴシック"     # 日本語
```

## ブランドチェックリスト

AIBODブランド準拠の確認に使うチェックリストです。

- [ ] コーポレートカラー3色（#1D2087 / #0068B6 / #00B3EC）のみ使用
- [ ] ティール・グリーン系が混入していない
- [ ] 本文テキストが BLACK (#1A1A1A)
- [ ] NAVYを本文テキストに使っていない（背景・バー専用になっている）
- [ ] 1〜2項目のアクセントはBLUE_LIGHT一色のみ
- [ ] 3項目はBLUE_LIGHT→BLUE→NAVYの順
- [ ] フォントが Poppins（英数字）+ 源ノ角ゴシック（日本語）
- [ ] 背景色に合ったロゴバリエーションを使用
- [ ] 絵文字を使っていない（番号01/02/03を使用）
- [ ] 表の罫線がBLACK（GRAY_LIGHTでない）
- [ ] 表ヘッダーがBLUE_LIGHT背景・WHITE文字
